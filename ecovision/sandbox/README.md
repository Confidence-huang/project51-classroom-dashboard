# EcoVision 最小二维沙盒

契约：1.0.0。纯HTML/CSS/JavaScript，无npm依赖，无外部字体/CDN，不连接MQTT。

整机装配、线束、控制与联调见[整机接线与联调手册](整机接线与联调手册.md)。模型、通风窗和窗帘的结构见[实体沙盒搭建方案](实体沙盒搭建方案.md)。

在项目根目录运行（Python 3.10+）：

```powershell
python -B -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8765/sandbox/>。服务只监听本机；结束按Ctrl+C。不能直接双击HTML，页面需要通过HTTP读取 `contracts/policy.json`。只建议在本机演示，未公开部署。

## 操作

- 默认模拟、暂停、0人、26℃。拖动人数与温度，点击“开始运行”，或用“+1秒 / +30秒”推进虚拟时间。
- 滑块是输入；下一次采样更新快照。视觉心跳关闭模拟停止收帧，5秒后过期，不立即把人数当0。网络关闭只改变模拟网络状态，本地控制继续。
- 规则从公共policy读取：3帧进入、连续无人30秒；28/27℃回差与5秒持续；视觉过期5秒，连续关键故障60秒关闭两路。
- “复现预设”从0秒重演至终点并暂停。“保存JSON”保存完整输入时间线；“导入复现”重建相同终点。文件格式仅属于沙盒场景容器，不是新增公共消息结构。无随机过程。
- “实物模式”目前显式显示未接入、所有状态未知、注入控件禁用。没有云端HTTP契约前不发送命令，不拿模拟快照填补真实数据。

快照与公共telemetry结构一致。模拟设备ID固定为 `sandbox`、boot_id固定用于确定性重演；`ts=null/time_valid=false`。模拟每秒采样并更新本地快照，**不是每秒发布MQTT**。OFFLINE快照未发到云端。fan_out/led_out只表示驱动逻辑。

## 演示脚本（约3分钟）

1. 重置，人数调2、温度调29℃，逐步推进：第3秒LED开，第8秒风扇开。
2. 温度调27.5℃并推进，风扇保持；调27℃推进6秒，风扇关。
3. 人数调0，推进30秒仍保持LED，再推进1秒关闭（首个0帧在调整后的下一秒）。
4. 加载“断网”预设：快照OFFLINE、NET_OFFLINE，两路仍开；说明仅本地模拟反馈。
5. 加载“视觉掉线”预设：UNKNOWN、人数null、两路关闭；展示时间线与虚拟73秒。
6. 保存JSON、重置、导入：终点完全一致。切实物模式，展示未知状态和禁用控制。

## 软件验证

需要Node.js 18+（当前验证24.19.0）和Python：

```powershell
node --test tests/sandbox/model.test.mjs
python -B -m unittest discover -s tests/sandbox -p "test_*.py" -v
```

导入限1MB、1小时、10000次输入事件，防止长时间阻塞页面。演示记录宜在1小时内保存。软件测试不是K230/STM32/EC200U实测。
